# Phase 1 audit and implementation plan

Audited base: `bd1046d2eb9d4ca7371d00a11e190158d613f403`. Notebook cell numbers below are zero-based JSON cell indices. Existing notebooks and CSVs are historical artifacts and remain unchanged.

## Findings (before implementation)

1. **P1: validation is not concept-disjoint.** All three requested notebooks, cell 2, use `arange(N_TR) % PER == PER-1`: one image of each concept goes to validation while other images of that concept train the model. This also assumes contiguous, equally sized concepts without checking metadata. Persist explicit image IDs, content hashes, concept IDs and a seeded concept partition; fit all normalization only on fit rows.
2. **P1: LOSO architecture selection sees the target subject.** 06b cell 6 selects BEST_SINGLE and routing layers from within-subject validation across all ten subjects; cell 7 reuses that selection in every LOSO fold. Epoch selection itself uses only the first three source subjects, which is source-only but unbalanced. Select every hyperparameter, layer, routing prior, loss weight and recovery setting in nested source-subject folds. Lock the choice before opening outer-target data. Use all source subjects for epoch validation. Reusing the historical L28 choice is a historical comparator, not proof of strict source-only selection.
3. **P1: upstream EEG preprocessing is transductive.** `02_loso.ipynb` and `04_trimodal_crosssubject.ipynb`, cell 4 PREP_SCRIPT, average repetitions and independently compute mean/std over images and time for each subject/split. The requested notebooks load those `_z16.npy` caches. Test inputs thus depend on all 200 test EEGs, even under plain scoring. Target calibration inputs depend on all 16,540 target training images before selecting k. Without actual cache provenance we cannot prove which generator made every historical file, but these loaders cannot certify inductive or k-only evaluation. Rebuild from pre-z-score arrays; do not try to undo float16 caches without saved statistics. Audit upstream dataset preprocessing separately, including any session-wide whitening.
4. **P1: calibration flags omit transductive scoring.** 09 cell 7 and 09b cell 7 apply CSLS to the whole test-query matrix while `transductive=False` is the default. CSLS column neighborhoods depend on other test EEGs. k=0 MM/SHRINK rows are not strict zero-calibration evidence. Separate adaptation from scoring; use cosine or a frozen source-reference correction for inductive evaluation. Label hybrid calibration + test-query methods separately from label-free transduction.
5. **P1: LOSO has false negatives.** 06b cell 7 repeats image IDs across nine subjects; cell 5 constructs symmetric diagonal cross-entropy. Batch duplicates have identical image targets yet off-diagonal matches are negatives, including EEGs of the same stimulus in the reverse direction. Use explicit identity masks, not batch positions. The planned set-positive loss is `logsumexp(all) - logsumexp(positives)` in both directions. It reduces exactly to the original objective for unique aligned pairs. Repeated identities still alter weighting; test deduplicated galleries or identity-balanced batches as separate ablations, not silent changes to the baseline.
6. **P2: metric assumptions can inflate results.** All three notebooks assume square, perfectly aligned query/gallery rows and count only strictly greater scores. All tied scores therefore yield 100% Top-1. Use explicit query IDs, unique gallery IDs, and deterministic gallery-ID tie-breaking. Reject missing identities, duplicate galleries and nonfinite scores. Report percentages and the candidate count.
7. **P2: visual normalization includes validation images.** 06b cell 4 uses all training-image features for mean/std, including validation rows. This does not use test-image labels, but compromises fully held-out validation. Fit on fit-concept images only; freeze for validation/test. Gallery embeddings themselves are legitimate retrieval candidates, but gallery-wide moment fitting is a separate declared adaptation choice.
8. **P2: calibration comparison limitations.** 09 L2-SP samples distractors independently of calibration IDs, allowing a positive image to reappear as a negative. 09b uses nested calibration draws (09 does not); its CV fits moment statistics before inner splitting, and folds split images rather than concepts. Refit preprocessing inside each concept CV fold. At k=1 centered Procrustes has zero cross-covariance and an unidentifiable rotation: use identity. SHRINK is a heuristic, not a mathematical never-worse guarantee. Time estimates count stimulus presentations, not a complete acquisition session. Three calibration draws are not three independently trained model seeds.
9. **P2: provenance and smoke mode.** Cache and model reuse is filename-only, with no data/config hashes or backbone revision. 06b SMOKE reduces loops but still requires real metadata/EEG/features and may extract InternViT; it does not create synthetic data. Calibration CSVs `calibration_v9.csv` and `calibration_v9b.csv` are absent from this commit, so the README calibration tables cannot be independently recomputed here.

## Implementation order

1. Add pure tested protocol helpers, explicit-ID retrieval, train-only normalization and the multi-positive loss. Keep the original diagonal objective as an explicit comparator.
2. Preserve EEGProject/ImageSide/Aligner from 06b in a new module; implement a paired training harness with identical initialization, batches, optimizer and schedule. Start on synthetic data. Refuse existing output directories and uncertified pre-normalized inputs.
3. Provide concept partition and source-only selection records, a 10-subject x 3-seed experiment manifest and data contract. Rebuild raw caches and select parameters in nested source folds before real runs. Never retrofit new strict labels onto historical results.
4. Add an optional frozen-text feature adapter: trainable text and EEG semantic heads, image-grounded prototypes, detached image/text-agreement gates. Keep the visual retrieval path and objective. Related-but-not-identical images remain distinct retrieval answers; mask ambiguous semantic negatives only in the auxiliary objective. Test zero, fixed and adaptive text weights. Success is measured in image retrieval, not lower text loss.
5. Run all outer folds, report Top-1/Top-5 separately by regime, average seeds/draws within subject before subject aggregation, and compare paired subject differences with uncertainty and multiplicity correction. Full runs require EEG data and pinned feature caches not committed here; synthetic checks cannot establish a retrieval improvement.
